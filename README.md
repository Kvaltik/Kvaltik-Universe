# 🌌 Kvaltík Universe – Alpha 0.1

První offline prototyp osobního centra aplikací a projektů Kvaltík.

## Spuštění
1. Stáhni repozitář pomocí **Code → Download ZIP**.
2. Rozbal ZIP.
3. Otevři soubor `index.html` v prohlížeči na počítači nebo telefonu.

**[📦 Stáhnout aktuální ZIP](https://github.com/Kvaltik/Kvaltik-Universe/archive/refs/heads/main.zip)**

## Co je dostupné
- Hlavní přehled a katalog 30 plánovaných modulů
- Integrovaný Project Manager v2.0
- Nástěnka, poznámky, úkoly a kalendář
- Místní ukládání souborů a dat ve prohlížeči

## Důležité
Toto je **offline HTML prototyp**, nikoli Windows EXE, Android APK nebo skutečný cloud. Některé moduly jsou jen položkami katalogu. Data jsou lokální pro daný prohlížeč a zařízení; pro přenos používej dostupné zálohování. Nemusí existovat automatická synchronizace ani přihlášení na server.
