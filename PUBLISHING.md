# Web Kvaltík

Statický český web bez instalace závislostí. Úvodní stránka: index.html. Původní aplikace: apps/universe.html (zachována beze změny).

## GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save.
Adresa: https://kvaltik.github.io/Kvaltik-Universe/

## Obsah
Katalog zachovává všech 38 existujících projektů, modulů a nápadů. Čtyři mají veřejný repozitář. Plány nejsou vydané aplikace. Sociální sítě jsou převzaté z původního webu.

## Aktualizace stažení
Dne 8. 10. 2026 ověřeny přes GitHub API: GameTools v0.1.0 a KvaltikHub v20.4.0. TSC Hub a Universe nemají Releases. Při novém vydání aktualizujte odkazy a verze v sekci stahovani i v poli projects v index.html, zkontrolujte HTTP dostupnost přiloženého EXE a datum ověření. Nikdy nevymýšlejte název souboru nebo URL.

## Lokální kontrola
Otevřete index.html v prohlížeči. Ověřte vyhledávání, kombinace filtrů, prázdné výsledky, detaily a jejich zavření Escape, mobilní nabídku a apps/universe.html.
